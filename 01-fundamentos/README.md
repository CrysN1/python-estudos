# Fundamentos de Python

Esta pasta reúne meus primeiros estudos e exercícios em Python, desenvolvidos durante minha jornada de aprendizado em programação e Análise de Dados.

## Conteúdos estudados

- Variáveis
- Tipos de dados
- Operadores
- Entrada e saída de dados
- Conversão de tipos
- Manipulação de strings
- Estruturas condicionais
- Estruturas de repetição
- Validação de dados

## Projeto

Como parte dos estudos, desenvolvi um sistema simples de cadastro de usuário utilizando Python.

O projeto permite:

- Cadastro de nome, idade, cidade, profissão e e-mail
- Classificação do usuário por faixa etária
- Validação básica de e-mail
- Manipulação e formatação de textos
- Cálculos simples utilizando os dados informados

## Objetivo

Construir uma base sólida em Python e desenvolver a lógica de programação necessária para utilizar a linguagem em projetos de Análise de Dados, automação e outras soluções.
